# Parish Connect — Quick User Guide

**Para sa:** Parish Priest at Parish Office Staff  
**Parish:** Immaculate Conception of the Virgin Mary Parish, Bani, Pangasinan  

Ito ay simpleng gabay para sa unang beses na gagamit ng **Parish Connect**. Sundin lang ang mga hakbang. Hindi kailangan ng technical knowledge.

---

## 1. Paano Mag-login

1. Buksan ang Parish Connect sa browser.
2. Ilagay ang **Email** at **Password** ninyo.
3. Pindutin ang **Sign In**.
4. Kapag tama ang login, pupunta kayo sa **Dashboard**.

**Paalala:** Walang “Forgot Password” o self-registration sa system. Kung hindi kayo maka-login, makipag-ugnayan sa Administrator.

---

## 2. Dashboard at Calendar

**Para saan?** Overview ng parish activities, bilang ng records, at parish calendar.

**Paano pumunta:** Sa kaliwang menu, piliin ang **Dashboard**.

### Calendar — mahahalagang galaw

| Galaw | Ano ang nangyayari |
|--------|---------------------|
| **Isang click** sa petsa | Makikita ang schedule ng araw na iyon |
| **Double-click** sa petsa | Maglalagay ng bagong record o event (kung allowed) |
| **Add Event** | Magdagdag ng manual calendar event (Holy Mass, Meeting, atbp.) |

### Paano gumawa ng bagong sacramental record mula sa calendar

1. **Double-click** ang petsa (o buksan ang day schedule).
2. Kung may events na sa araw na iyon, lalabas ang **Scheduled on this Date**.
3. Piliin ang **Add Sacramental Record**.
4. Piliin ang sacrament (Baptism, Confirmation, Marriage, Death Record, o Conversion).
5. Pindutin ang **Continue**, punan ang form, tapos **Save**.

**Mahalagang paalala**

- **Hindi** pwedeng gumawa ng bagong record sa **nakaraang petsa** (past date).
- Ang events na galing sa sacramental records ay **view-only** sa calendar. Para i-edit, buksan ang original record sa module nito.
- Ang **Mass Intention** ay hindi ginagawa sa calendar create list — gawin ito sa **Mass Intentions** page.

---

## 3. Sacramental Records

**Para saan?** Encoding at pagtingin ng Baptism, Confirmation, Marriage, Death, at Conversion records.

**Paano pumunta:** Sidebar → **Sacramental Records** → piliin ang module (hal. **Baptismal Records**).

### Karaniwang hakbang (lahat ng sacramental modules)

1. Gamitin ang **Search** para hanapin ang pangalan o record number.
2. Pindutin ang **Filter** kung gusto ninyong piliin ang year, minister, requirements status, atbp.
3. **Add … Record** — para sa **Old / historical** records (manual record number at year).
4. Sa table, pindutin ang **View** (mata) o **Edit** (lapis).
5. Sa View dialog, maaari ninyong i-generate ang certificate.
6. Sa Edit form, pindutin ang **Save** kapag tapos na.

### Old Record vs New Record

- **New Record** — galing sa **calendar** (scheduled / upcoming). Auto ang record number.
- **Old Record** — galing sa **Add** button ng module (historical encoding). Manual ang record number/year.

### Requirements Checklist

May checklist (hal. Birth Certificate, Baptismal Certificate). Ito ay **paalala lang**. Kahit Incomplete, **pwede pa ring i-Save** ang record.

---

## 4. Certificate Generation

**Para saan?** Pag-print o PDF ng official certificate mula sa naka-save na record.

**Available para sa:** Baptism, Confirmation, Marriage, Death, at Conversion.

### Paano

1. Buksan ang record → **View**.
2. Pindutin ang **Generate … Certificate**.
3. Lalabas ang **Certificate Preview**.
4. Piliin:
   - **Print** — bubukas ang Print Preview ng browser  
   - **Download PDF** — magda-download ng PDF file  
   - **Close** — isara ang preview  

**Paalala:** Kailangan **naka-save** ang record bago mag-generate. Hindi nababago ang original record kapag nag-generate ng certificate.

---

## 5. Mass Intentions

**Para saan?** Pag-manage ng Mass Intention requests at schedules.

**Paano pumunta:** Sidebar → **Mass Intentions**.

### Paano gumamit

1. **Add Intention** para gumawa ng bagong request (default status: **Pending**).
2. Gamitin ang **Search** at **Filters**.
3. **View** / **Edit** / **Delete** sa table (Delete ay may confirmation).
4. I-update ang status kapag kailangan:
   - **Pending** → **Scheduled** (kapag may Mass date/time na)
   - **Scheduled** → **Offered** (pagkatapos ng Mass) — may confirmation dialog
   - **Scheduled** → **Cancelled** — may optional **Cancellation Reason**

### Read-only rule

Kapag ang status ay **Offered** o **Cancelled**:

- Hindi na pwedeng i-edit o i-delete  
- Form ay **read-only**  
- Ito ay para hindi mabago ang finished / cancelled intentions  

---

## 6. Manage Ministers

**Para saan?** Listahan ng priests/ministers na ginagamit sa forms.

**Paano pumunta:** Sidebar → **Manage Ministers**.

1. **Add Minister** para magdagdag.
2. Punan ang name, title, position, assignments, at status.
3. **Save**.
4. Gamitin ang **Search** at **Filters** (Status, Position, Assignment).

**Paalala:** Karaniwang **Active** ministers lang ang naka-assign sa bagong records.

---

## 7. Reports

**Para saan?** Pag-generate ng reports para sa office / filing.

**Paano pumunta:** Sidebar → **Reports**.

### Paano gumawa ng report

1. Piliin ang **Report Type** (Baptism, Confirmation, Marriage, Death, Conversion, o Mass Intention reports).
2. Piliin ang **Year**, **Month** (kung applicable), at **Minister**.
3. Pindutin ang **Generate Report**.
4. Sa Preview:
   - **Export PDF** — i-download bilang PDF  
   - **Print** — i-print gamit ang browser  
5. Sa **Recent Reports**, pindutin ang **View** para buksan ulit ang dating report settings.

---

## 8. Profile (Account)

**Para saan?** Personal account details at password.

**Paano pumunta:** Sidebar → **Profile**, o account menu sa itaas (kanang bahagi).

### Magagawa ninyo

1. I-update ang **Personal Information** (name, phone, address, birthday, gender) → **Save Changes**.
2. Tingnan ang Role, Status, Last Login (read-only).
3. **Change Password** → ilagay ang current at new password → **Update Password**.
4. Quick links: **Dashboard**, **Reports**, **Logout**.

**Paalala:** Ang **Email** ay hindi pwedeng baguhin dito.

---

## 9. Logout

Puwede ninyong mag-logout sa:

1. Sidebar (ibaba) → **Logout**  
2. Account menu (itaas kanan) → **Logout**  
3. Profile → **Logout**  

---

## Quick Tips

1. **I-save lagi** ang record bago mag-generate ng certificate.
2. **Double-click** sa calendar = create; **single-click** = view lang.
3. **Past dates** = hindi na pwedeng magdagdag ng bagong record.
4. Kung may **Unsaved Changes** warning, piliin kung mananatili kayo sa page o aalis (maaaring mawala ang hindi naka-save).
5. Gamitin ang **Search** at **Filter** para mabilis makahanap ng records.
6. **Offered / Cancelled** Mass Intentions ay locked na — i-double check bago i-mark.
7. Kung may error sa login o walang access, makipag-ugnayan sa Administrator.
